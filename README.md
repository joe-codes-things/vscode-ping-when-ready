# Ping When Ready

A personal VS Code extension idea: notify me when a VS Code agent has finished
responding to my message, using both a pop-up notification and a sound.

This project is in its early planning stage. Detecting the end of an agent
response and choosing how to play the sound still need to be explored; the
extension is not implemented yet. The goal is private, personal use rather
than publishing a public extension.

See [Project Onboarding](./docs/ONBOARDING.md) for project context,
[Feature Ideas](./docs/FEATURE-IDEAS.md) for open design questions, and
[Bugs](./docs/BUGS.md) for reported issues.
